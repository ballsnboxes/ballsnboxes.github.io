# ballsnboxes.github.io

Сайт игры Balls & Boxes: страница игры, политика конфиденциальности и `app-ads.txt`
для рекламных сетей. Публикуется через GitHub Pages прямо из ветки `main`,
без сборки (`.nojekyll`).

| Путь | Что это |
|------|---------|
| `/` | Страница игры (RU), `/en/` — EN |
| `/privacy/` | Политика конфиденциальности, RU и EN на одной странице. **Этот адрес указан в магазинах и в игре — не переносить** |
| `/app-ads.txt` | Строки авторизованных продавцов рекламы. Должен лежать в корне домена. Это файл РСЯ как есть (кабинет → Настройки → Общие → app-ads.txt): наша строка `yandex.com, 333178719, DIRECT`, остальное — реселлеры Яндекса. Обновлять заменой целиком, не руками; строку VK Рекламы (её даёт кабинет VK) после замены дописать обратно |

Политика описывает, что именно передают обе рекламные сети: myTarget SDK с MyTracker (VK)
и Yandex Mobile Ads SDK с AppMetrica (Яндекс). Любое
изменение в игре, которое это меняет (новый SDK, окно согласия, аналитика), сначала
отражается здесь, потом выходит в магазины.

Фоновое видео первого экрана (`assets/video/hero.mp4` и постер `hero.jpg`) собирается
из записи прохождения скриптом `tools/site_hero.py` в репозитории игры — править его
там, а не перекодировать файлы здесь.

Локальный просмотр: `python3 -m http.server -d . 8000` → http://localhost:8000/
